# M7 Dua Kartu — Implementation Plan

Spec: `docs/superpowers/specs/2026-10-05-m7-dua-kartu-design.md` (disetujui, D1/D2 sesuai usulan).

**Prinsip:** TDD per task, aturan 1:1 GAS terbaru (`PaymentLogic.js`, `SpreadsheetOps.js`,
`FlazzOps.js`, `SummaryOps.js`, `Code.js`). Transaksi tanpa grup-2 harus berperilaku persis
seperti sekarang — seluruh test lama tetap hijau tanpa diubah.

### Task 1: Schema dan tipe
- `db/schema.sql`: 4 kolom grup-2 di `create table penggunaan_bbm` + `alter table ... add column if not exists`
  (pola kolom `seq`); 2 kolom kartu ke-2 di `jalur_pengiriman` dengan pola yang sama.
- `LaporanRow` + `laporanRow()` helper test: 4 field baru (default `''`/`0`).
- Verifikasi: `node scripts/migrate-sheets.mjs <xlsx>` dry-run → "Kolom dibuang" kosong.

### Task 2: Logika murni (`src/logic/laporan.ts`)
Test dulu di `tests/logic/laporan.test.ts`, lalu implementasi:
- `PaymentState` + kunci `cardBbm2/biayaBbm2/cardTol2/biayaTol2`; `cardFields` tidak berubah.
- `group2FromRow`, `cardGroups`.
- `flazzBbmShare`, `flazzTolShare`, `isFlazzRowForCard`, `flazzCardCharge` lewat `cardGroups`.
- `distinctFlazzCardsOf(state)`; hapus `distinctFlazzCards` setelah semua pemanggil pindah.
- `rowBbmTotal`, `rowTolTotal`; `groupMonthly` memakai keduanya.
- `buildFlazzChecks(..., group2?)` menambah `BBM kartu 2` / `tol kartu 2`.
- `DuplicateKey` + `isDuplicateRow` menambah `biaya_bbm_2`, `biaya_toll_2`.
- `Prefill`/`mapPrefillRow` dan `RecentItem`/`buildRecentList`: field grup-2 + `total_bbm`, `total_toll`.

### Task 3: Route (`src/routes/laporan.ts`)
Test dulu di `tests/routes/laporan.test.ts` (describe baru `grup-2 (kartu kedua)`):
- POST: dua kartu terpotong; saldo kartu 2 kurang → 409 dan tidak ada yang terpotong/tersimpan;
  kartu 2 tidak ada → 409 label `BBM kartu 2`; usage dibuat untuk kedua kartu; nominal grup-2
  tanpa kartu tidak menyentuh saldo; duplikat mempertimbangkan grup-2.
- PUT: field grup-2 dipertahankan bila tidak dikirim; pindah kartu grup-2 (lama +, baru −);
  kartu grup-2 tujuan tidak ada → 400; edit KM/bar/liter menghitung ulang `perubahan_bar` & `km_per_liter`.
- DELETE: dua saldo kembali, usage kedua kartu dikembalikan.
- DELETE `/flazz`: grup-2 BBM Flazz dilepas (kartu kosong, nominal tetap, saldo kembali);
  boleh bila hanya grup-2 yang Flazz; tol tidak berubah.
- GET dashboard/prefill: field grup-2 dan total.

### Task 4: Frontend
- `input.js`: bagian "Tambah pengeluaran dengan kartu ke-2" (4 field), prefill grup-2,
  `validateForm`/`buildPayload` grup-2 (test di `tests/frontend/input-helpers.test.ts`).
- `edit.js`: bagian "Kartu ke-2 (opsional)" (4 field) dikirim di PUT.
- `transaksi.js`: kolom biaya memakai `total_bbm`/`total_toll`, penanda `2 kartu`.

### Task 5: Rilis
1. `npm run typecheck`, `npm test`.
2. Terapkan schema ke Supabase (`scripts/apply-schema.mjs`, butuh `SB_DB_PASSWORD` dari pengguna).
3. Migrasi ulang: dry-run lalu `--apply`; cek `TRX-1790403411499` (`biaya_bbm_2 = 500000`).
4. Deploy (persetujuan pengguna), smoke test, push, README.
